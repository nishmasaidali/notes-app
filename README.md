# 📝 Notes App

A Google Keep-style notes application built with **React**. Users can create, edit, search, organize, pin, archive, and delete notes. Notes are stored in the browser using **Local Storage**.

## ✨ Features

* Create, edit, and delete notes
* Pin and archive notes
* Search, filter, and sort notes
* Select multiple notes
* Bulk delete and archive
* Add tags and categories
* Choose different note colors
* Character limits and validation
* Duplicate note prevention
* Created and updated timestamps
* Bold, italic, bullet, and numbered formatting
* Keyboard shortcuts
* Responsive design
* Local Storage persistence

## 🛠️ Technologies Used

* React
* JavaScript
* HTML
* CSS
* Vite
* Local Storage

## 🚀 How to Run

```bash
git clone https://github.com/nishmasaidali/notes-app.git
cd notes-app/note
npm install
npm run dev
```
